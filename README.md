# سامانه استعلام

بدون لاگین. سه مرحله: **ترسیم و اطلاعات → پیش‌نمایش → دانلود**.

## اجرا

```bash
npm install
npm run dev   # http://localhost:5175
```

## رفتارها

- **مرحله ۱ (نقشه):** ابزار نقطه و پلیگان. پنل کناری فقط `نام` و `آدرس` دارد.
- **لایه کاربری (نامرئی):** از `/zoning.geojson` لود می‌شود؛ هیچ لایه مرئی به نقشه اضافه نمی‌کند و ظاهر نقشه را تغییر نمی‌دهد — فقط با `queryPoint/queryPolygon` در `src/utils/zoning.js` مقدار کاربری خوانده و کنار اطلاعات نمایش داده می‌شود.
  - نقطه → کاربری نقطه
  - پلیگان → کاربری مرکز + فهرست کاربری‌های متقاطع (اگر چند زون را قطع کند)
- **مرحله ۲ (پیش‌نمایش):** قالب واحد شامل نام، آدرس، کاربری، مساحت/مختصات + دو تصویر (ماهواره‌ای و نقشه خیابان) + جمله «این استعلام رسمی نیست و برای اخذ استعلام رسمی به شهرداری مراجعه کنید.»
- **مرحله ۳ (دانلود):** دانلود PNG برگه (html2canvas) + چاپ/PDF.
- **بک‌اند:** فعلاً لوکال (`public/zoning.geojson` + `localStorage`). برای اتصال سرور واقعی کافی است URL در `loadZoning()` با اندپوینت GeoJSON/WFS شهر جایگزین شود؛ ساختار `karbari` در properties حفظ شود.

## دیتای نمونه

`public/zoning.geojson` شش زون تستی اطراف تهران (مسکونی/تجاری/فضای سبز/آموزشی/صنعتی/مذهبی) دارد.
